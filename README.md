# Par ou Ímpar

Jogo de par ou ímpar no terminal, feito em Python.

## Como funciona
- O programa sorteia um número de 1 a 10.
- Você palpita "par" ou "impar".
- Ele diz se você acertou ou errou e mostra o resultado.
- Digite "sair" pra encerrar e ver seu placar de acertos e erros.

## Como rodar
Precisa de Python 3 instalado (ou do app Pydroid 3 no celular).
Roda o arquivo par_ou_impar.py.

## O que eu aprendi
random, if/else, while, break, input e variáveis de contagem.
